# Руководство по репозиторию

**Статус:** Утверждённое направление проекта

Дерево репозитория описывает разработку VibeOS. Оно не повторяет структуру `/System`, `/Users` или `/Volumes` на установленной машине VibeOS.

```text
src/
├── boot/      ранняя загрузка и загрузчик
├── arch/      код, зависящий от ISA процессора
├── platform/  прошивки, таблицы платформы и профили машин
├── kernel/    базовые механизмы ядра
├── ipc/       объекты, Keys, Links и протокол Relay
├── drivers/   шины, классы устройств и драйверы
├── storage/   VFS, VaultFS, тома и проверка
├── network/   сетевой стек и протоколы
├── runtime/   runtime C17 и библиотеки приложений
├── security/  доверие, подписи, криптография и политики
├── services/  привилегированные пользовательские службы
├── ui/        композитор, UI SDK, рабочая среда и доступность
└── apps/      пользовательские приложения
```

У каждого каталога одна ответственность. Подсистема использует другую только через документированный публичный интерфейс. Приватные заголовки и структуры данных не пересекают границы. Новая междоменная зависимость требует небольшого контракта, теста и документации.

В корне также находятся `docs/`, `tools/`, `tests/`, `assets/`, `third_party/` и `.github/`. Генерируемые результаты не попадают в Git и игнорируются через `.gitignore`.

Перед изменением кода или документации прочтите [руководство по участию](CONTRIBUTING.md).
