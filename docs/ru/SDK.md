# Платформа приложений и Vibe SDK

**Статус:** Утверждённое направление; реализация запланирована

VibeOS предоставит нативную платформу приложений. C17 — первый официальный язык приложений. Программы используют Origin, Facet, Canvas, Vault Kit и Meridian Kit, а не POSIX или прямой доступ к ядру.

Планируемый Vibe SDK предоставит профиль toolchain C17, заголовки и ABI-библиотеки, CLI `vibe`, профили QEMU, шаблоны, примеры, упаковку VPK, подпись и документацию для host-систем Windows, macOS и Linux.

По умолчанию приложение получает минимальные Keys: собственный процесс, AppData, окно Canvas и журналирование. Файлы, сеть, буфер обмена, уведомления, фоновый режим, устройства и административные возможности выдаются через явную декларацию manifest и одобрение пользователя либо системы.

Vibe SDK планируется как будущий отдельный репозиторий. Он не будет создан, пока у VibeOS не появятся минимальный стабильный Application ABI и выпускаемый SDK bundle. VibeOS остаётся источником истины для ABI, исходников библиотек, спецификаций и тестов совместимости.
