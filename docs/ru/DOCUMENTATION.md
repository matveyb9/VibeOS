# Правила документации

**Статус:** Утверждённое направление проекта

Английский — основной язык документации VibeOS. Русский — обязательный второй язык. У каждого опубликованного документа есть парная страница в `docs/en/` и `docs/ru/`, а в корне используются `README.md` и `README_RU.md`.

Каждая страница начинается с центрированного переключателя языка до заголовка. Активный язык выделяется жирным, второй ведёт прямой ссылкой на парный документ. Внутренние ссылки остаются в дереве текущего языка. Переключатель языка — единственная обычная ссылка между деревьями языков.

У каждой страницы одна задача. Объяснения отвечают на вопрос, почему существует решение. Справка и спецификации фиксируют точные контракты. Гайды показывают выполнение задачи. Учебные главы ведут через полный путь обучения. ADR фиксируют одно архитектурно значимое решение и последствия.

Технические документы начинаются со статуса: `Черновик`, `Утверждено`, `Заменено` или `Устарело`. Изменение утверждённого ABI, формата или архитектурного контракта требует обновления спецификации, при необходимости руководства по миграции и ADR для значимого решения.

Руководства по сборке, запуску и отладке обязаны указывать host-платформу, целевую платформу, режим запуска и статус поддержки. Документация VibeOS не должна молча предполагать Linux, одну CPU-архитектуру или только QEMU.
