# Среды разработки

**Статус:** Запланировано; команды появятся вместе с toolchain этапа Project Foundation

Документация VibeOS будет явно покрывать каждую комбинацию host-системы и цели. Проект не предполагает молча Linux, host x86_64 или единственный путь загрузки.

| Host-среда | Начальный статус документации |
|---|---|
| Windows x86_64 и ARM64 | Запланировано через нативные инструменты или документированную совместимую среду |
| macOS x86_64 и Apple Silicon | Запланировано |
| Linux x86_64 и ARM64 | Запланировано |

| Цель или профиль запуска | Начальный статус |
|---|---|
| QEMU x86_64 UEFI | Первый обязательный профиль |
| QEMU x86_64 legacy BIOS | Первый обязательный профиль |
| Физический PC Baseline x86_64 | Запланировано после базовых драйверов Atlas |
| QEMU AArch64 `virt` | Запланировано после стабилизации ABI x86_64 |
| QEMU RISC-V RV64GC `virt` | Исследовательская цель после AArch64 |

Каждый будущий гайд укажет host, цель, путь загрузки, последовательность команд, подключение отладчика, путь serial-лога, ожидаемый результат и статус поддержки. Нереализованный гайд будет прямо сообщать об этом, а не показывать непроверенные команды.
