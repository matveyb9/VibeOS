# Roadmap

**Status:** Living plan

VibeOS is built in working stages. Each stage ends with a reproducible result, tests, and matching English and Russian documentation.

## Project Foundation

Create the toolchain profile, QEMU profiles, build scripts, testing entry points, and initial developer guides for Windows, macOS, and Linux hosts.

## Boot and kernel foundation

Bring up Prelude for x86_64 UEFI and legacy BIOS, define Dawn Context, initialise Pulse memory and interrupts, then add tasks, Keys, Relay, and diagnostics.

## Storage and installation

Add Atlas baseline drivers, VaultFS, journals, Live mode, Live + Vault, A/B installation, Recovery, and Safe Session.

## Runtime and packages

Deliver Origin, Facet, application startup, VPK validation, Parcel, and the first native application workflow.

## Desktop and applications

Deliver Prism, Canvas, Horizon, Harbor, Prompt/Cue, Vector, Studio, Guide, and the rest of the core application path. Large projects such as Orbit and Sonata develop in explicit sub-stages rather than being declared complete early.

## Release line

Stabilise supported profiles, signed images, recovery, A/B rollback, documentation, hardware validation, and public alpha then beta releases.
